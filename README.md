# 扣子账号浏览器

**一个窗口，多个扣子账号。各自登录，点击头像切换。**

把工作号、测试号和日常账号集中在一个窗口中，支持添加五个以上独立入口。普通浏览器也能通过不同用户配置使用多账号，本工具把账号列表和网页切换放在同一界面。

[下载最新版 2.3.6](https://github.com/Ian6733227/coze-account-browser/releases/latest) · [使用说明](USAGE.md) · [CLI 控制](CONTROL-CLI.md) · [问题反馈](https://github.com/Ian6733227/coze-account-browser/issues)

适用于 **Apple 芯片 Mac，macOS 13 或更高版本**。基于 Electron/Chromium，不需要另装 Chrome 或 Node.js。非扣子官方产品；安装包使用 ad-hoc 签名，尚无 Developer ID 签名与 Apple 公证。没有提供 Intel Mac、Windows 或 Linux 安装包。

## 可以做什么

| 功能 | 使用方式 |
|---|---|
| 多账号独立登录 | 点击“＋”添加入口，在每个入口的扣子网页分别登录；各自保存本机登录资料。 |
| 快速切换 | 点击头像，或使用 ⌘1–⌘9；编号按完整账号列表固定排列，隐藏入口也占编号。 |
| 识别账号 | 自动同步扣子昵称和头像，支持自定义名称、备注及头像；实际身份以扣子页面为准。 |
| 收起侧栏 | 保留头像入口，为网页留出空间；“全部打开”保留文字提示。 |
| 保留后台网页 | 切换账号时其他已打开网页继续运行；“全部打开”一次打开多个入口。 |
| 按需释放资源 | “关闭网页”关闭该入口页面，保留登录资料，可能中断页面工作。 |
| 重启恢复 | 恢复最近选中账号和允许的页面路径，不恢复地址中的查询/片段，不自动重开所有后台账号。 |
| 帮助与控制 | 离线使用帮助、中文教程视频，以及供其他软件调用的本机 CLI/IPC。 |

## 三步开始

1. 从[下载页](https://github.com/Ian6733227/coze-account-browser/releases/latest)下载 `CozeAccountBrowser-2.3.6-macos-arm64.zip`，核对同页 `SHA256SUMS.txt`。解压后将应用放入 `~/Applications`（用户的应用程序目录）。不要下载 Source code 来代替安装包。
2. 打开应用，选择左侧入口，在右侧扣子页面自行登录。其他账号分别添加、分别登录。
3. 点击左侧头像切换；登录过期时按扣子页面提示重新登录。退出应用会关闭本地网页，登录资料保留。

升级前正常退出旧版，替换应用即可；保留用户资料目录。首次打开可参考 [Apple 官方说明](https://support.apple.com/zh-cn/102445)，不要关闭系统整体安全保护。

## 2.3.6 的变化

- 保留原版多账号、头像同步、自定义、隐藏恢复、关闭网页、帮助视频和 CLI 功能，改为接近扣子网页的中性灰白界面。

- 配置损坏时停止加载并提示排查，附带只读元数据检查工具；不会自动合并、恢复或删除登录资料。
- 汇总此前内部 2.3.2–2.3.5 的加载错误提示、确认目标保护、CLI 版本检查和最近页面恢复。

## 使用边界

- 没有完成相同负载的 Brave 内存对比，不承诺更省内存。网页越多通常越占资源。
- CLI 能列出/切换账号、打开允许的扣子页面、查询加载状态；不能向扣子内部 Agent 发任务、取消任务或获取执行结果。
- 退出关闭的是本地网页，服务端任务是否继续由扣子决定。
- 原子写入不保证断电持久性，清除登录资料涉及的两个文件不是同一事务。若账号列表缺失但已有 Sessions，使用者应停止启动并按[恢复说明](embedded/RECOVERY.md)排查；程序目前仍可能生成默认列表，并不会自动拦截这种情况。
- 自动化测试采用合成网页和隔离资料；没有登录真实扣子账号。实际账号、身份及工作流程需使用者自行确认。
- 本轮原生测试环境为 Apple 芯片 Mac、macOS 27.0.1；没有完成 macOS 13 真机检查或公众下载后带 quarantine 的首次打开验收。

公开源码和安装包不含使用者的账号列表、Cookie 或聊天记录。请勿把本机资料目录上传到仓库、Issues 或第三方模型。详细说明见[使用与开发](USAGE.md)。
