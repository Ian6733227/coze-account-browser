# 应用图标来源

智进化应用图标使用现有官方标志中的箭头，置于 macOS 圆角底板。
- `zhijinhua-app.png` 用于应用内和「关于」。
- `ZhijinhuaApp.icns` 提供 16 到 1024 像素尺寸，供 Dock 和 Finder 显示。

## 历史资源

用于用户本机“扣子账号浏览器”的应用图标；这是本地账号切换工具，不是扣子官方桌面客户端。

- 原始资源：coze-official-logo.png（822 × 809），来自扣子官网公开脚本引用。
- 来源页面：https://www.coze.cn/
- 原件 URL：https://lf-coze-web-cdn.coze.cn/obj/eden-cn/lm-lgvj/ljhwZthlaukjlkulzlp/space/logo-icon.png
- 获取日期：2026-10-03。
- coze-multi-account.png：2026-10-09 按用户要求以原标志为参考，经图像生成工具加入多账号卡片；2026-10-10 用户同意采用。
- CozeIcon.icns：用 macOS sips 转换新图标各标准尺寸，再用 iconutil 打包。
- 新图标只用于本工具的识别，不表示扣子官方背书。
- CozeIcon.icns 是早期版本的应用图标。

The platform switcher loads bundled PNGs from `embedded/ui/platform-icons`.
