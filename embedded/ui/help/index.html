常见问题

在哪里登录？

登录入口在右侧的扣子网页中。左侧的账号名称只是本机账号槽位，不代表已经登录。选中后，按右侧网页的提示操作即可。

看不到右侧网页怎么办？

先选中左侧账号；若显示“打开当前账号”，点击它。仍未加载时，用应用的“网页”菜单刷新或返回首页，并检查网络连接。

能同时登录五个以上账号吗？

可以。点击加号添加更多独立账号。每个账号首次分别登录，之后可在同一窗口点击头像切换。不要向同一个账号槽位登录不同账号，避免混淆。

绿色点就是已登录吗？

不是。绿色点表示这个账号的网页正在运行，实际登录状态要看扣子网页。它也不能用来判断任务是否完成。

怎样只显示头像？

点击网页顶部左侧的侧栏切换按钮，收起账号栏；再次点击可展开。可使用“同步头像昵称”获取当前账号资料，也可通过“编辑”自定义名称。

暂停网页会退出登录吗？

暂停会释放这个账号网页占用的部分内存，保留本机登录资料。但可能中断页面里的工作，建议任务结束后再暂停。重新打开时是否需要登录由扣子决定。

关闭软件以后，任务还会继续吗？

本地网页会关闭。扣子服务端的任务是否继续，由扣子自身机制决定。本工具不能保证退出后所有任务仍在运行。

这比普通浏览器更省内存吗？

目前没有完成同场景内存对比测试，不能保证。优势是把多个独立账号放在一个窗口中管理；同时打开的网页越多，通常越占资源。

CLI 能做什么？

当前 CLI 可以列出账号、切换账号和打开扣子页面。完整命令示例见下方“CLI 控制说明”。

登录资料能跟着安装包分享吗？

不能，也不需要。分享公开发布的安装包即可；不要分享本机应用数据目录、浏览器存储或 Cookie。其他人安装后使用自己的账号登录。
