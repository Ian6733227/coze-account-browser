常见问题

在哪里登录？

登录入口在右侧的扣子网页中。左侧的账号名称只是本机账号槽位，不代表已经登录。选中后，按右侧网页的提示操作即可。

看不到右侧网页怎么办？

先选中左侧账号；若显示“打开当前账号”，点击它。仍未加载时，用应用的“网页”菜单刷新或返回首页，并检查网络连接。

能同时登录五个以上账号吗？

可以。点击加号添加更多独立账号。每个账号首次分别登录，之后可在同一窗口点击头像切换。不要向同一个账号槽位登录不同账号，避免混淆。

绿色点就是已登录吗？

不是。绿色点表示这个账号的网页正在运行，实际登录状态要看扣子网页。它也不能用来判断任务是否完成。

怎样只显示头像？

点击网页顶部左侧的侧栏切换按钮，收起账号栏；再次点击可展开。可使用“同步头像昵称”获取当前账号资料，也可通过“编辑”自定义名称。

关闭网页会退出登录吗？

暂停会释放这个账号网页占用的部分内存，保留本机登录资料。但可能中断页面里的工作，建议任务结束后再关闭网页。重新打开时是否需要登录由扣子决定。

重新打开会回到哪个账号？

启动时打开所有未隐藏账号，并恢复上次选中的账号和可恢复的扣子页面路径。第三方登录页面、网址参数和未提交输入不恢复。

点红色 × 后，任务还会继续吗？

点红色 × 会最小化窗口，原来的网页继续运行。点 Dock 图标可恢复窗口。按 ⌘Q 退出时，本地网页会关闭。扣子服务端的任务是否继续，由扣子自身机制决定。本工具不能保证退出后所有任务仍在运行。

这比普通浏览器更省内存吗？

目前没有完成同场景内存对比测试，不能保证。优势是把多个独立账号放在一个窗口中管理；同时打开的网页越多，通常越占资源。

CLI 能做什么？

当前 CLI 可以列出账号、切换账号和打开扣子页面。完整命令示例见下方“CLI 控制说明”。

登录资料能跟着安装包分享吗？

不能，也不需要。分享公开发布的安装包即可；不要分享本机应用数据目录、浏览器存储或 Cookie。其他人安装后使用自己的账号登录。

隐藏、关闭和清除有什么区别？

隐藏账号入口只隐藏列表项，网页可能继续运行；勾选“显示已隐藏账号”可找回。关闭网页保留登录。编辑中的“清除此账号登录资料…”会先取消未保存的编辑，再确认清除这一个入口的网站登录、缓存、网站本机数据和同步昵称头像；保留入口名称、备注、自定义头像。其他账号、下载文件和云端内容不受影响；清除不可撤销，需要重新登录。

快捷键和昵称状态怎样理解？

⌘1–⌘9按完整列表固定编号；隐藏账号不会让后续编号前移。昵称头像可能是缓存，待确认不代表登出。异常退出出现保存未确认提示时，请检查网页。

排序与删除账号

长按、双击或右键左侧账号，打开快捷菜单。选择“上移一位”或“下移一位”调整显示顺序，重启后会保留，账号编号照旧。也可以直接从菜单选择“删除账号…”。

选中左侧账号，点击顶部“编辑”，再点“删除账号并清除登录资料…”。核对弹窗里的名称和编号后，由你本人确认。会关闭该入口的网页并清除它的本机登录和网站数据，从列表中移除；不会注销扣子网站账号，也不影响其他入口、已下载文件和云端内容。

默认选择取消。若清除失败或超时，入口保留供重试；清除完成但列表保存失败时会明确提示。最后一个入口也可删除，之后点击“＋”重新添加并登录。“隐藏账号”仅隐藏入口，当前网页可能仍显示；“仅清除登录资料”则保留列表入口。
